### 帖子正文（Markdown / 富文本）

对于用惯了大屏手机的人来说，单手操作永远是个无解的痛点。

三星的 **One Hand Operation+ (OHO+)** 被誉为移动端最强手势软件，但它死死焊在三星手机上；**Quick Cursor** 解决了大屏单手触达，但高级功能需要买断且功能相对单一；**FooView（FV悬浮球）** 曾是神作，但长期闭源、权限庞大且界面停留在几年前；而在国内极客圈深受欢迎的 **SearchEVO** 也是独立工具。

既然大家都在找替代品，不如把这些经典交互的精髓打通，做一款真正属于 Android 极客的现代化开源神器——**X手势（XGesture）**。

---

### 🌟 核心功能一览

#### 1. 任何手机都能用的「完整版 OHO+ 手势」
- 屏幕左右/上下边缘触发区自由调节，完美复刻直线、斜上、斜下、长滑悬停等多段手势。
- 支持扇形面板、蜂窝菜单、应用索引和任务切换，配备专属横屏触发手柄，玩游戏看视频两不误。

#### 2. 大屏单手救星「悬浮光标指针」（Quick Cursor 级体验）
- 边缘向内滑动唤出摇杆指针，大拇指只需在屏幕下半部轻推，光标即可精准点击屏幕顶部的任意按钮，单手轻松掌控 6.7~6.9 英寸大屏。

#### 3. 悬浮球「全离线 OCR 识图与以图搜图」（FooView 体验进化）
- 拖拽悬浮球直接取词、OCR、分词，无障碍节点与本地 OCR（PaddleOCR ONNX / ML Kit）智能无缝降级。
- 聚合 Google、Yandex、SauceNAO、TinEye 等 10+ 搜图引擎，内置悬浮窗快速预览，完全支持导入 SearchEVO 规则。

#### 4. 深度玩机与系统级整合
- **Shizuku / Root / LSPosed 深度赋能**：无需 root 即可调用系统 Shell、拉起未导出的非公开 Activity，彻底摆脱系统对无障碍的后台误杀。
- **主流系统小窗完美兼容**：深度适配小米 MIUI / HyperOS 自由小窗、魅族 Flyme 小窗以及原生 Android Freeform。
- **OTP 验证码提取**：收到短信自动解析验证码，配合悬浮窗一键填入。

#### 5. 纯净、开源与现代设计
- 采用 Kotlin 2.4 + Jetpack Compose + Miuix 设计语言，原生级流体阻尼动效与实时高斯模糊。
- **AGPL-3.0 协议全开源**：零广告、零内购、零追踪隐私权限，纯本地离线优先。
